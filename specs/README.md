# Specs

What the game does, one file per area. `TEMPLATE.md` is the starting point for a
new one, and `CLAUDE.md` in the repo root describes the flow.

Specs are numbered in the order they were written. The number is an identifier,
not a priority, and it never changes once a spec exists.

| Spec | Covers |
| --- | --- |
| [0001](0001-board.md) | The board, its cells, and how it fills the window |
| [0002](0002-pieces.md) | The seven tetrominoes, rotation, and the bag |
| [0003](0003-falling.md) | Gravity, moving, locking, and line clears |
| [0004](0004-next-and-hold.md) | The next piece and the hold slot |
| [0005](0005-scoring.md) | Score, levels, and topping out |
| [0006](0006-game-flow.md) | Menu, pausing, and game over |
| [0007](0007-sound.md) | What makes a sound |
